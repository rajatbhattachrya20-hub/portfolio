# Rajat Bhattacharya - Digital Portfolio

A modern, responsive, and glassmorphic developer portfolio showcasing software engineering projects, data structures & algorithm visualizers, technical skills, and credentials.

🌐 **Live Demo**: [https://rajatbhattachrya20-hub.github.io/portfolio](https://rajatbhattachrya20-hub.github.io/portfolio)

---

## 🚀 Features

- **Cyber-Glassmorphism UI**: Smooth ambient orbs, dark/light theme switching, and fluid typography.
- **Interactive Developer Terminal**: Embedded bash-like console (`rajat@guest:~$`) with custom command handlers.
- **Live DSA Visualizer Mini Lab**: In-browser algorithm visualizer for Bubble Sort, Selection Sort, and Insertion Sort with real-time comparison/swap telemetry.
- **Dynamic Typewriter & Particle Engine**: Native HTML5 Canvas particle network.
- **SEO & Performance Optimized**: Semantic HTML5 markup with complete meta tags.

- **Typography & Icons**: Google Fonts (*Outfit*, *Inter*, *JetBrains Mono*), Font Awesome 6
- **Hosting**: GitHub Pages
